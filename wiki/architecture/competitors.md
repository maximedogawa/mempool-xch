## Who they are

One person, a self-hosted Chia full node, a Python indexer with SQLite, plain JavaScript and CSS
served as files, no framework. Independent, not affiliated with Chia Network Inc. Cookie banner
with three categories (Google Analytics 4 and AdSense behind consent, DNT and GPC honoured),
Terms of use, Legal notice (private individual in the Netherlands, Dutch law), Privacy and
Cookie policies, a footer disclaimer (no financial advice, data as is, do your own research).
Public JSON API with about 30 endpoints, no auth, no streams. 16 languages plus a pirate mode.

## Own node

To read from your own node, point Settings at it: see the
[custom or local node guide](../guides/custom-node.md), which also covers the built-in dev proxy
and what a still-syncing node can and cannot serve. A hosted own-node gateway with an indexer is
planned as a separate project.

## Second data provider: Druid Garden

[Druid Garden](https://druid.garden) (Galactechs LLC) runs a cluster of Chia full nodes and
exposes the standard full-node RPC publicly at `https://druid.garden/<method>` (verified
2026-09-16: `GET /get_blockchain_state` answers with CORS `*`). Docs at
`druid.garden/api/full-node`; plans: Free 15 calls/min and 100,000/month, Starter 120/min
(25 USD), Pro 300/min (100 USD), Enterprise with on-premise options. No indexed API and no
WebSocket, so it complements Coinset as a failover for plain RPC (no failover planned). They also publish
GardenOS and `helm-chia-nodes` for running own nodes.
